# Private security overview

This project is private, confidential, and owner-controlled. Only the owner and the trusted partner should access it.

## Safety goals

- keep active and inactive account activity private
- block suspicious or unauthorized transfers instantly
- require device trust for private access
- keep all actions in an immutable-style audit log
- allow browser monitoring only in the owner’s own authorized browser profiles
- keep keys and secrets outside the repo

## Private deployment model

- local host or private infrastructure only
- no public deployment for real account data
- public docs should not contain API keys or account details
- all security and tracking is designed to protect the owner's private assets
